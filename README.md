\## Educational Purpose and Ethical Use



\*\*This project was developed strictly for educational purposes as part of my cybersecurity learning journey during my Pinnacle internship. It is intended to help understand keyboard event monitoring, endpoint security, and the potential risks associated with keylogging software.\*\*



Keyloggers can pose serious threats to privacy and security when misused. This project is not intended for malicious activity, unauthorized surveillance, credential theft, or the collection of private information.



\### Responsible Use Guidelines



\- \*\*Authorized testing only:\*\* Run the program only in controlled lab environments or on systems you own or have explicit permission to test.

\- \*\*Respect privacy:\*\* Never monitor another person's keyboard activity without their informed consent.

\- \*\*Protect sensitive information:\*\* Do not use this project to collect passwords, authentication tokens, financial information, or other confidential data.

\- \*\*Learn, don't exploit:\*\* Use this project to understand security risks and develop knowledge of defensive cybersecurity practices.



\## Disclaimer



This repository is provided solely for educational and research purposes. The author does not encourage, endorse, or authorize the use of this software for malicious purposes, unauthorized monitoring, surveillance, or data theft.



\*\*Users are responsible for ensuring that their use of this project complies with applicable laws, privacy requirements, and authorization boundaries.\*\* The project should only be used in environments where appropriate permission has been obtained.



The goal of this project is to promote cybersecurity awareness and responsible learning, not to facilitate harm.
